# Product

## Register

product

## Users

开发者、企业 IT 管理员、AI 服务提供商。他们需要管理多个 LLM API 密钥、控制成本、监控使用情况、为团队成员分配配额。主要场景：配置渠道、创建令牌、查看日志、充值额度、管理用户权限。

## Product Purpose

New API 是一个 LLM 网关和 AI 资产管理系统。Classic UI 是管理后台界面，用于配置 API 渠道、管理令牌、查看使用日志、控制成本。界面需要清晰展示大量数据（表格、图表、统计），操作流程高效（快速创建/编辑/删除），信息层级分明。

## Brand Personality

专业、可靠、高效。面向技术用户，不需要过度装饰。清晰的数据可视化比视觉特效更重要。像一个专业的仪表盘 - Grafana 的数据密度 + Stripe 的交互清晰度。

## Anti-references

- 消费级社交应用的卡片式布局（信息密度太低）
- 过度动画和渐变效果（分散注意力）
- 深色模式下低对比度的灰色文字（难以长时间阅读）
- 复杂的多级导航（用户需要快速在功能间切换）

## Design Principles

1. **信息密度优先** - 表格、图表、统计数据是核心，要清晰易读
2. **快速操作** - 常用功能（创建令牌、查看日志）不超过 2 次点击
3. **状态可见** - 关键指标（余额、使用量、错误率）始终可见
4. **数据驱动** - 用图表和数字说话，减少文字描述
5. **一致的交互模式** - 相同操作（CRUD）使用相同的模式

## Accessibility & Inclusion

- 表格支持键盘导航和筛选
- 图表提供数据表格备用视图
- 颜色编码（成功/警告/错误）不仅依赖颜色，还有图标和文字
- 支持浅色/深色主题切换
- 长时间使用的舒适度（合理的行高、字号、对比度）
