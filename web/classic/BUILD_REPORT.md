### 部署步骤

1. **复制构建产物到服务器**
   ```bash
   # 将 dist/ 目录内容复制到 web 服务器
   cp -r dist/* /path/to/web/root/
   ```

2. **配置 Nginx (示例)**
   ```nginx
   location / {
       root /path/to/web/root;
       try_files $uri $uri/ /index.html;
   }
   ```

3. **启动后端服务**
   ```bash
   # Go 后端
   ./new-api
   ```
