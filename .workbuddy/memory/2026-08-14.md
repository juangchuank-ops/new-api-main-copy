## 深色模式下图表白底修复（classic 前端）

- 用户反馈：数据看板「模型数据分析」区域在深色模式下背景发白；要求顺带排查其他同类问题。
- 根因：classic 前端的 `<VChart>` 组件未在 spec 中显式指定 `theme` 与 `background`，仅依赖 `useDashboardCharts`/`ModelPerformanceCharts` 里 `useEffect` 中调用的 `initVChartSemiTheme`。`useEffect` 在 React 提交后执行，而图表在同一渲染周期已挂载，首次渲染时 Semi 主题尚未注册完成，VChart 退回默认浅色（白底）主题。
- 修复方式：参照默认前端（`web/default`）做法，为每个 `<VChart>` 显式注入 `theme`（来自 `useActualTheme`）与 `background: { fill: 'transparent' }`，并以 `key` 含 theme 值触发主题切换时重建图表。
- 改动文件：
  - 新增 `web/classic/src/hooks/useChartTheme.js` —— 基于 `useActualTheme` 返回 `theme: 'dark'|'light'` 的轻量 hook。
  - `web/classic/src/components/dashboard/ChartsPanel.jsx`（模型数据分析面板，6 张图表全部应用）—— 新增 `renderSpec` 合并 theme + 透明背景，`key` 加 theme。
  - `web/classic/src/components/dashboard/StatsCards.jsx`（统计卡片趋势小图）—— 同上处理。
  - `web/classic/src/components/table/model-pricing/modal/components/ModelPerformanceCharts.jsx`（模型性能延迟/可用性趋势图）—— 移除 `initVChartSemiTheme` 的 useEffect 与对应 import，改用 `useChartTheme` + 显式 spec 字段。
- 构建：`cd web/classic && bun run build` 成功；`go build -o new-api.exe .` 成功（exe 18:17 生成），已嵌入新 classic dist。当前无 new-api 进程运行，需手动启动 `new-api.exe`。
